# NIPS2017 smoke subset

This directory contains the first 16 records in the official `images.csv`
ordering from version 2 of Google Brain's NIPS 2017 Adversarial Learning
Development Set.

Source: <https://www.kaggle.com/datasets/google-brain/nips-2017-adversarial-learning-development-set>

Official archive SHA-256:
`cc63f38ebf9351de7981d7d3463c51143d1dd0c3f0d2944d56193f35036ac12b`

Every included row identifies its author, original landing page, author
profile, and individual license. All 16 selected images are licensed under
[CC BY 2.0](https://creativecommons.org/licenses/by/2.0/). The unchanged
metadata in `images.csv` supplies the required attribution.

`SHA256SUMS` pins every included PNG and the attribution CSV so the package
can be checked after cloning.

This subset is for pipeline smoke testing only. It is not the complete
1,000-image benchmark and must not be used to report NIPS2017 accuracy or
transferability metrics.
